# Local

Эта папка хранит **локальные проектные инструкции**, которые полезны команде прямо внутри репозитория.

Важно:

- `local/` в репозитории — это **не** место для runtime-данных приложения
- runtime-данные приложения идут в `%LOCALAPPDATA%\AdbControl`
