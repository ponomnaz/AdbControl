# Local

`local/` хранит внутренние проектные заметки, которые полезны прямо в репозитории.

Важно:

- это не место для runtime-данных приложения
- runtime-данные живут в `%LOCALAPPDATA%\AdbControl`

## Что здесь лежит

- [design-system.md](design-system.md) — зафиксированная дизайн-система и визуальные принципы
- [installer.md](installer.md) — заметки по installer / uninstall

## Чего здесь не должно быть

- логи приложения
- кэш
- импортированные APK
- любые runtime-файлы, создаваемые после установки или запуска
