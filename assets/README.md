# Assets

Здесь лежат все репозиторные визуальные ресурсы проекта.

## Папки

- `icons/` — иконки приложения, панели, toolbar, installer icon
- `images/` — изображения для README, мокапов и docs
- `branding/` — логотипы, splash, фирменные элементы

## Текущий логотип приложения

Исходник:

- `icons/icon_adb.svg`

Сгенерированные продуктовые форматы:

- `icons/icon_adb.png`
- `icons/icon_adb.ico`

## Правила

- не хранить runtime-generated файлы в `assets/`
- исходники и финальные экспортированные иконки лучше класть рядом, но с понятными именами
- если ассет нужен только installer-слою, класть его в `build/installer/assets/`
